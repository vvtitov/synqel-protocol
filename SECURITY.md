# Security policy

## Supported versions

Security fixes are released for the latest minor version of `@synqel/sdk` and `@synqel/mcp` on npm.

| Version | Supported |
|---------|-----------|
| 0.3.x   | Yes       |
| < 0.3   | No        |

## Reporting a vulnerability

Report vulnerabilities privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability** ([direct link](https://github.com/vvtitov/synqel-protocol/security/advisories/new)). Do not open a public issue.

Include the affected package and version, a description of the impact, and steps or code to reproduce it. You should get a first response within 7 days. Once a fix is released, the advisory is published with credit to the reporter unless you ask otherwise.

## Scope

In scope: the published packages (`@synqel/sdk`, `@synqel/mcp`) and the protocol specification in `docs/`. Issues in third-party dependencies should be reported upstream; we will update the dependency once a fix is available.
